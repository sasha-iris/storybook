Prototypes

Fifteen working pages, built only from component-library classes — no page-local CSS. Real product data, numbers untouched, so some rows are genuinely broken. Nothing is calculated live, and estimated values say so on the page.

Customer segments

Two variants of a segments-page redesign. Case study.

  • Segments list — variant 2 Forty real segments, sorted so the ones that cannot be trusted come first.
  • Segment detail — variant 2 One segment, its definition in plain language, and the working behind the parse.
  • Segments list — variant 1 The first variant, keeping the four separate data states rather than collapsing them.
  • Segment detail — variant 1 Detail page for the same dataset in the first visual language.
  • Segment builder Building a segment from conditions, with an estimate panel that refuses to name customers it cannot know.
  • Compare segments Two segments side by side. Documented as answering a different question than the live comparison does.

Profit & Loss

Comparison, edit mode and formula display on a 24-row statement. Case study.

  • P&L statement — v2 Dollar variance, run-rate forecasting, edit mode, and a detail panel with the row's formula.
  • Assumptions & configuration — v2 The settings behind the statement: baselines, forecast models, accrual treatment.
  • P&L statement — first version Kept live and untouched, so the two iterations can be compared directly.
  • Assumptions — first version The configuration page as it stood before the second pass.
