A component library developers can copy from

47 components documented so that the story shows the class that ships. Mostly an audit, and mostly saying no.

Role
Sole designer — Figma extraction, CSS, stories, docs
Product
Financial analytics platform for ecommerce brands
Consumers
Storybook, the production CSS, a low-code environment
Live
The library

Problem

Every family had stories and the build was clean, but a story could be drawn with inline styles and no library class in the markup — a picture of a component, not the component. Copying it gave a developer something that would not ship.

I extracted all 447 classes from the shipped CSS and checked every family against them by computed style, not by eye. Twelve failed and were rebuilt.

Decisions

  • Deleted components that were never designed A KPI card, datepicker presets, a metric card, several select and search types existed in the docs but not in Figma. Rule since: not in Figma, not in Storybook.
  • Did not delete CSS that looked orphaned 33 rules with no story and no page using them. The low-code environment consumes the same file and I could not see inside it. Documented as orphaned instead.
  • Fixed accessibility in the token, not on the page Success green measured 3.0:1 on white; the token moved to #007a55, with the reason recorded beside it. Page-level fixes would not have travelled.
  • Stopped after four attempts at the Actions tab Interaction logging does not work in this static build. Each attempt is written up as a known limitation, so nobody repeats the investigation.
  • Kept the two CSS files in lockstep Preview and export consume different files. Auditing the pair found six token conflicts — one, a blue-versus-purple --color-bg-primary, was breaking form checkboxes.
  • Flat sidebar, one slot per family The Components/ wrapper was removed and the rule written into the project instructions with a counter-example, so it stays removed.
  • Real content in every story Placeholder text hides truncation, wrapping and spacing bugs. Written into the story patterns next to the argTypes template.

What building on it exposed

Product pages were built with library classes only, so every gap became a finding: the drawer was unusable and a page used a modal instead; the progress bar had no danger variant, so a broken state had been coloured with the chart palette's trend-down pink; two tokens measured below AA at the sizes pages actually used them.
