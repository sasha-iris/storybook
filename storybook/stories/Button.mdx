# Button

Iris button component — 7 colors × 5 sizes × 2 outline modes × icon-only.

## Usage

### HTML

<Source code={`<button class="btn btn-primary btn-md">Button text</button>`} language="html" />

### React

<Source code={`<button className="btn btn-primary btn-md">Button text</button>`} language="jsx" />
