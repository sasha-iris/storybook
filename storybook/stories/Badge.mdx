# Badge

Status badges for labeling content, categorizing items, and indicating state.

## Basic Usage

### HTML

<Source code={`<span class="badge badge-lg badge-indigo">In review</span>`} language="html" />

### React

<Source code={`<span className="badge badge-lg badge-indigo">In review</span>`} language="jsx" />

## Dismissible

Removable filter chips with × button.

### HTML

<Source code={`<span class="badge badge-lg badge-indigo">
  <span>In review</span>
  <button type="button" aria-label="Remove In review" style="display:inline-flex;background:none;border:none;cursor:pointer;padding:0;">
    <svg width="16" height="16" viewBox="0 0 20 20" fill="currentColor" aria-hidden="true">
      <!-- x-mark icon -->
    </svg>
  </button>
</span>`} language="html" />

### React

<Source code={`import { XMarkIcon } from '@heroicons/react/24/outline';

<span className="badge badge-lg badge-indigo">
  <span>In review</span>
  <button type="button" aria-label="Remove In review" style={{ display: 'inline-flex', background: 'none', border: 'none', cursor: 'pointer', padding: 0 }}>
    <XMarkIcon className="w-4 h-4" />
  </button>
</span>`} language="jsx" />

## Metric Chip

Two-line priority badge: label + metric value.

### HTML

<Source code={`<span class="badge badge-red badge--metric">
  Critical
  <span class="badge--metric__sub">11.0% rev</span>
</span>`} language="html" />

### React

<Source code={`<span className="badge badge-red badge--metric">
  Critical
  <span className="badge--metric__sub">11.0% rev</span>
</span>`} language="jsx" />
