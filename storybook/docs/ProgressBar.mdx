# Progress Bar — HTML & React Code Snippets

Communicates completion status of a task or process. Each section shows both HTML and React versions with independent copy buttons.

## Basic Usage

### HTML

<Source code={`<div style="width:100%;">
  <div style="font-size:12px;font-weight:500;color:#6b7280;text-align:right;">50%</div>
  <div style="height:6px;background:#e5e7eb;border-radius:2px;overflow:hidden;">
    <div style="height:100%;width:50%;background:#5850ec;border-radius:2px;"></div>
  </div>
</div>`} language="html" />

### React

<Source code={`<div style={{ width: '100%' }}>
  <div style={{ fontSize: '12px', fontWeight: 500, color: '#6b7280', textAlign: 'right' }}>
    50%
  </div>
  <div style={{ height: '6px', background: '#e5e7eb', borderRadius: '2px', overflow: 'hidden' }}>
    <div style={{ height: '100%', width: '50%', background: '#5850ec', borderRadius: '2px' }} />
  </div>
</div>`} language="jsx" />

### React

<Source code={`const colors = {
  primary: '#5850ec',
  green: '#31c48d',
  orange: '#ff8a4c',
};

const ProgressBar = ({ value, color }) => (
  <div style={{ width: '100%', marginBottom: '20px' }}>
    <div style={{ fontSize: '12px', fontWeight: 500, color: '#6b7280', textAlign: 'right' }}>
      {value}%
    </div>
    <div style={{ height: '6px', background: '#e5e7eb', borderRadius: '2px', overflow: 'hidden' }}>
      <div style={{ height: '100%', width: \`\${value}%\`, background: colors[color], borderRadius: '2px' }} />
    </div>
  </div>
);

// Usage
<ProgressBar value={75} color="primary" />
<ProgressBar value={75} color="green" />
<ProgressBar value={75} color="orange" />`} language="jsx" />
