## With Icons

Left icon, right icon, and icon-only variants.

### HTML

<Source code={`<!-- Left icon -->
<button class="btn btn-primary btn-md">
  <svg width="20" height="20" viewBox="0 0 20 20" fill="currentColor" aria-hidden="true">
    <!-- heroicon -->
  </svg>
  <span>Label</span>
</button>

<!-- Right icon -->
<button class="btn btn-primary btn-md">
  <span>Label</span>
  <svg width="20" height="20" viewBox="0 0 20 20" fill="currentColor" aria-hidden="true">
    <!-- heroicon -->
  </svg>
</button>`} language="html" />

### React

<Source code={`import { StarIcon, ArrowRightIcon } from '@heroicons/react/24/outline';

// Left icon
<button className="btn btn-primary btn-md">
  <StarIcon className="w-5 h-5" />
  <span>Label</span>
</button>

// Right icon
<button className="btn btn-primary btn-md">
  <span>Label</span>
  <ArrowRightIcon className="w-5 h-5" />
</button>`} language="jsx" />

## Icon Only

Icon-only button with square aspect ratio.

### HTML

<Source code={`<button class="btn btn-icon btn-primary btn-md" aria-label="Action">
  <svg width="20" height="20" viewBox="0 0 20 20" fill="currentColor" aria-hidden="true">
    <!-- heroicon -->
  </svg>
</button>`} language="html" />

### React

<Source code={`import { StarIcon } from '@heroicons/react/24/outline';

<button className="btn btn-icon btn-primary btn-md" aria-label="Action">
  <StarIcon className="w-5 h-5" />
</button>`} language="jsx" />
